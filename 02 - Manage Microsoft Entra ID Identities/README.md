# 02 - Manage Microsoft Entra ID Identities

Lab AZ-104: création et gestion d'identités dans Microsoft Entra ID (Azure Active Directory), incluant le réseau virtuel associé aux services principaux.

## Tasks

- **Task 1: Create a virtual network with subnets using the portal** — Création du VNet CoreServicesVnet et des sous-réseaux SharedServicesSubnet / DatabaseSubnet.
- **Task 2: Create and configure user accounts** — Création d'un utilisateur interne (az104-user1) et invitation d'un utilisateur externe (guest).
- **Task 3: Create groups and add members** — Création du groupe de sécurité "IT Lab Administrators" et ajout des membres/propriétaires.
